Phases

7 Structured Phases

1. Build the Feature

The orchestrator parses PRDs, reviews Figma coverage, generates TRDs per platform, launches agents in parallel, deploys backend to staging, and validates stitching.

/scaffold /scaffold-backend /scaffold-frontend /scaffold-ios /scaffold-web

2. Make It Beautiful

Adds premium animations, glassmorphism, shimmer states, charts, spring transitions, and UI polish without changing feature behavior.

/lovable /lovable-ios /lovable-web

3. Optimize Performance

Runs deep Compose optimization: skipping, prefetch, animation cleanup, layer isolation, image optimization, and benchmark APK generation.

/compose-perf

4. Polish the Copy

Reviews every user-facing string for clarity, tone, grammar, capitalization, CTA quality, and legal/product risks.

/copy-review

5. Add Analytics

Reads Google Sheet event specs, discovers architecture patterns, generates tracking wrappers, and wires events into UI interactions.

/analytics-ingest /analytics-ingest-ios

6. Verify Events

Checks event definitions, Mixpanel registration, property integrity, and actual firing data across environments.

/analytics-verify

7. Cross-Platform Audit

Compares Android vs iOS vs source-of-truth analytics specs to detect mismatches, missing properties, and dead events.

/analytics-audit

When NOT To Use It

❌ Features touching more than 3 existing screens significantly
❌ Multi-service backend migrations or infra overhauls
❌ Open-ended PRDs with unresolved design questions
❌ Platform-level redesigns or navigation refactors
✅ Best for focused, independently shippable features
